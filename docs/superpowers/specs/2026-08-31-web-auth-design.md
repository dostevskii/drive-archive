# 외부 접속용 웹 인증 설계

**작성일:** 2026-08-31 · **대상 버전:** v0.4.0 · **상태:** 설계 승인됨, 구현 전

---

## 무엇을 만드는가

지금 `drive-archive serve`는 127.0.0.1에만 열리고 인증이 없습니다. 여기에 비밀번호
게이트를 세워, 밖에서도 들어올 수 있게 하되 비밀번호를 통과한 사람만 인덱스를 보게
합니다. 화면은 데스크톱과 모바일 양쪽에서 쓸 수 있어야 합니다.

**서버 자체는 계속 127.0.0.1에만 뜹니다.** 밖으로 내보내는 일은 앞에 붙는 터널이
맡습니다. 이 문서에서 "외부 접속"은 그 터널을 거쳐 들어오는 것을 뜻합니다.

## 요구사항

사용자가 지정한 것을 그대로 옮깁니다.

1. 외부에서 접속할 수 있다.
2. 처음 들어오면 `PASSWORD:`가 뜬다. `SEARCH:` 줄의 폼을 그대로 쓰고, 라벨만
   대문자 `PASSWORD:`로 한다.
3. 입력하는 동안 `*`로 입력 중임을 표시한다.
4. 비밀번호를 묻는 동안 하단 리스트뷰는 보이지 않는다.
5. 올바른 비밀번호를 넣으면 목록을 볼 수 있다.
6. 모바일 화면과 데스크톱 화면이 있고, 적응형으로 동작한다.
7. 컴퓨터가 켜져 있을 때만 접속되고, 꺼져 있으면 접속되지 않는다.
8. 비밀번호 설정과 변경은 터미널에서만 할 수 있다. 웹에서는 안 된다.
9. `install`이 비밀번호를 반드시 받는다. 설치를 마쳤다면 비밀번호가 있다.
10. 로컬에서 볼 때도 터널을 거친다. 서버를 LAN에 직접 열지 않는다.

## 왜 이 설계인가

### 인증에 예외를 두지 않는다

**모든 요청에 인증을 요구합니다. 로컬 접속도 예외가 아닙니다.**

로컬에서 볼 때도 터널을 거칩니다. `cloudflared`가 127.0.0.1로 붙으므로 서버 입장에서
외부 접속과 로컬 접속은 애초에 구별되지 않습니다. "로컬이면 통과"라는 규칙을 두면
터널 뒤로 그대로 뚫립니다. 접속 주소로 신뢰를 판단하지 않습니다.

**비밀번호가 설정되어 있지 않으면 `serve`가 뜨지 않습니다.** 실행을 거부하고
`drive-archive passwd`를 안내합니다. `install`이 비밀번호를 반드시 받으므로 정상
경로에서는 이 상황이 생기지 않고, `install` 없이 `serve`만 부른 경우에만 걸립니다.

인증 없이 여는 경로를 남기지 않는 이유는, 남겨 두면 언젠가 그 상태로 터널이 붙기
때문입니다. 인덱스에는 파일 이름과 경로가 통째로 들어 있습니다.

### 비밀번호는 인덱스 DB에 넣지 않는다

인덱스는 스캔이 통째로 갈아엎고 `forget`으로 지워지는 데이터입니다. 인증 정보와
수명이 다릅니다. `%LOCALAPPDATA%\drive-archive\auth.json`에 따로 둡니다.

### argon2 크레이트를 쓴다

이 프로젝트는 MCP도 웹 서버도 직접 구현했지만, 암호 해시는 예외로 둡니다.
크레이트가 12개 늘어납니다(argon2, blake2, digest, password-hash, base64ct, subtle,
generic-array, typenum, block-buffer, crypto-common, cpufeatures, rand_core).
`cargo tree -e normal`로 실측한 값이고, 릴리스 빌드 크레이트가 60개에서 72개가
됩니다.

직접 구현한 PBKDF2도 표준 테스트 벡터로 검증할 수 있었지만, 암호 해시는 정확성
외에 부채널 저항 같은 것이 걸려 있어 검증된 구현에 맡깁니다.

### 난수는 크레이트를 늘리지 않는다

salt와 세션 토큰에 쓸 난수는 `BCryptGenRandom`으로 얻습니다. `windows` 크레이트에
`Win32_Security_Cryptography` feature만 더 켜면 되고, 크레이트 수는 늘지 않습니다.
실제로 호출해 32바이트를 받아 확인했습니다.

## 구조

| 파일 | 변경 |
|---|---|
| `src/auth.rs` (신규) | 비밀번호 저장·검증, 세션, 실패 잠금, 난수 |
| `src/serve.rs` | 헤더·쿠키 파싱, POST 수용, `/api/login`, 전 경로 인증 검사 |
| `src/web/index.html` | PASSWORD 게이트, 적응형 레이아웃, 터치 |
| `src/main.rs` | `passwd` 서브커맨드 |
| `src/task.rs` | 작업 이름·XML 매개변수화, serve 작업 정의 |
| `src/install.rs` | 비밀번호 강제 입력, serve 작업 등록·해제 |
| `Cargo.toml` | argon2, windows feature |

### auth.rs가 하는 일

- `set_password(&str)` — argon2id로 해시해 `auth.json`에 쓴다
- `verify(&str) -> bool` — 저장된 해시와 대조한다
- `is_configured() -> bool` — 비밀번호가 설정되어 있는가
- `issue_session() -> String` — 32바이트 난수 토큰을 발급하고 만료와 함께 보관
- `check_session(&str) -> bool` — 유효한 토큰인가 (만료된 것은 지운다)
- `note_failure(ip)` / `is_locked(ip)` — 실패 카운터와 잠금

세션과 잠금 상태는 프로세스 메모리(`Mutex<HashMap>`)에만 둡니다. 서버를 다시 띄우면
전부 무효가 됩니다. 단순하고, 오히려 안전합니다.

## 인증 흐름

### 비밀번호 설정 (터미널)

```
drive-archive passwd
```

`SetConsoleMode`로 `ENABLE_ECHO_INPUT`을 해제하고 입력받습니다. 터미널에서는 별표도
찍지 않는 것이 관례이고, 어깨너머로 길이가 새지 않습니다. 확인용으로 두 번 받아
일치할 때만 저장합니다.

기존 비밀번호를 묻지 않습니다. 이 명령을 실행할 수 있다는 것은 이미 그 계정으로
로그인해 있다는 뜻이고, 그 시점에 `auth.json`을 직접 지울 수도 있습니다. 확인 절차를
더해도 실제로 막는 것이 없습니다.

웹에는 비밀번호를 바꾸는 경로를 만들지 않습니다.

### 설치할 때 반드시 받는다

`install`은 비밀번호를 받아야 끝납니다. 같은 입력 루틴을 쓰고, 두 번 받아 일치할 때까지
되묻습니다. 이미 설정되어 있으면 다시 묻지 않고 "이미 설정되어 있습니다. 바꾸시려면
`drive-archive passwd`를 실행하세요"라고 알립니다.

설치를 마친 상태에는 비밀번호가 반드시 있습니다. `serve`가 인증 없이 열릴 수 있는
경우를 없애는 것이 이 강제의 목적입니다.

### 로그인 (웹)

```
POST /api/login   body: {"password": "..."}
  성공 → 200 + Set-Cookie: da=<토큰>; HttpOnly; SameSite=Strict; Path=/; Max-Age=86400
  실패 → 401 {"error":"wrong"}
  잠김 → 429 {"error":"locked","seconds":N}
```

`Secure` 플래그는 요청에 `X-Forwarded-Proto: https`가 있을 때만 붙입니다. Cloudflare
Tunnel이 이 헤더를 붙여 주므로 외부 접속에는 붙고, 로컬 `http://127.0.0.1`로 직접 볼
때는 빠져 쿠키가 정상 저장됩니다.

**세션은 24시간 유효하고, 쓰는 동안 계속 밀립니다.** 인증된 요청이 들어올 때마다 만료를
24시간 뒤로 다시 잡고 갱신된 쿠키를 응답에 실어 보냅니다. 매일 쓰는 한 다시 칠 일이
없고, 하루 동안 손대지 않으면 만료됩니다. 컴퓨터를 계속 켜 두어 서버가 떠 있어도 이
규칙은 같습니다 — 세션을 살려 두는 것은 서버의 수명이 아니라 사용자의 접속입니다.

### 요청 검사

비밀번호가 설정되어 있으면 `/`와 `/font.woff2`를 뺀 모든 경로가 유효한 세션 쿠키를
요구합니다. 없으면 401을 돌려주고, 화면은 그것을 보고 게이트로 돌아갑니다.

`/`를 열어 두는 이유는 게이트 화면 자체가 그 HTML이기 때문입니다. 이 HTML에는 인덱스
내용이 들어 있지 않습니다.

검사를 통과한 요청은 그 자리에서 세션 만료를 24시간 뒤로 밀고, 갱신된 쿠키를 응답에
같이 실어 보냅니다.

### 무차별 대입 방어

IP별로 실패를 세고 5회에서 60초 잠급니다. 성공하면 초기화합니다. argon2 검증 자체가
느려 초당 수십 회가 한계지만, 외부에 열리는 이상 잠금이 있어야 합니다.

IP는 `X-Forwarded-For`의 첫 값을 쓰고, 없으면 소켓의 상대 주소를 씁니다. 터널 뒤에서는
모든 접속이 127.0.0.1로 보여, 소켓 주소만 쓰면 한 사람의 오타가 전체를 잠급니다.

**그런데 이 헤더는 공격자가 직접 붙일 수 있습니다.** 요청마다 다른 값을 넣으면 IP별
카운터가 매번 새것이 되어 잠금을 통째로 우회합니다. 그래서 전역 카운터를 함께 둡니다 —
어느 IP에서 왔든 실패가 20회 쌓이면 60초 동안 전부 잠급니다. 이 카운터는 헤더로
갈라지지 않으므로 위조로 피할 수 없습니다.

## HTTP 계층 변경

지금 `read_request_target`은 GET만 받고 헤더를 통째로 버립니다. 세 가지가 필요해집니다.

1. **헤더 보관** — `Cookie`, `X-Forwarded-Proto`, `X-Forwarded-For`를 읽어야 한다
2. **POST 수용** — `/api/login`이 본문을 받아야 한다 (`Content-Length`만큼 읽는다)
**바인딩 주소는 127.0.0.1 그대로 둡니다.** 바꿀 수단을 만들지 않습니다.

외부 노출은 전부 터널이 맡습니다. 같은 집 와이파이에서 휴대폰으로 볼 때도 터널
주소로 들어갑니다. 서버가 LAN에 직접 열릴 일이 없으므로 `--host` 같은 옵션이 필요
없고, 없는 편이 안전합니다 — 옵션이 있으면 언젠가 인증이 약한 상태로 그 옵션이
쓰입니다.

`Request { method, path, query, headers, body, peer }` 구조체로 바꾸고, 본문 길이에
상한(8KB)을 둡니다.

## 화면

### PASSWORD 게이트

`SEARCH:` 줄과 같은 `.bar` 폼을 씁니다. 라벨만 `PASSWORD:`로 바꾸고, 입력한 글자 수만큼
`*`를 그립니다. 커서·깜빡임·IME 처리는 지금 코드를 재사용합니다.

게이트 상태에서 숨기는 것은 표와 목록입니다 — `#rule`·`#head`·`#list`·`#more`, 그리고
하단의 `#vim`·`#mode`. 타이틀 막대와 알파벳 데코 줄은 남깁니다.

`#where`는 남깁니다. 틀렸을 때 `WRONG PASSWORD`를, 잠겼을 때 남은 시간을 띄울 자리가
필요하고, 그 줄에는 인덱스 내용이 들어가지 않습니다.

화면을 열면 `/api/drives`를 먼저 부릅니다. 200이면 이미 세션이 있는 것이라 바로 목록을
띄우고, 401이면 게이트를 띄웁니다.

### 적응형

41칸을 유지하고 글자 크기만 화면 폭에 맞춥니다.

- 데스크톱은 18px 상한이라 **지금 화면이 그대로**입니다
- 좁아지면 `1ch`가 줄어 41칸이 그대로 들어갑니다
- `--line`을 글자 크기에 비례시킵니다 (지금 21px / 18px = 7/6)
- JS의 `LINE = 21` 상수를 CSS 변수에서 읽도록 바꿉니다 (`fitList()`가 이 값에 의존)

`1ch`와 font-size의 비율은 FiraD2로 실측해서 넣습니다. 41칸이 화면에 정확히 들어가야
하므로 추정값을 쓰지 않습니다.

### 터치

지금은 클릭이 선택, 더블클릭이 열기입니다. 모바일에서 더블탭은 확대로 먹힙니다.
**이미 선택된 행을 다시 탭하면 열리게** 하고, 데스크톱 더블클릭은 그대로 둡니다.

## 자동 실행

`serve`를 로그온 트리거로 등록해, 컴퓨터를 켜서 로그인하면 창 없이 떠 있게 합니다.
컴퓨터가 꺼지면 접속이 끊깁니다 — 요구사항 7이 이렇게 성립합니다.

`task.rs`가 지금 `TASK_NAME` 상수 하나에 묶여 있어 `setup`·`remove`·`exists`·`run_now`가
모두 그 이름을 박아 씁니다. 작업 이름과 XML을 인자로 받도록 매개변수화하고, 기존
호출부는 sync 작업을 넘깁니다.

serve 작업이 sync 작업과 다른 점:

| 항목 | sync | serve |
|---|---|---|
| 트리거 | 마운트 이벤트 + 로그온 | 로그온만 |
| 인자 | `sync --drive $(DriveName)` | `serve --no-open` |
| `ExecutionTimeLimit` | `PT4H` | `PT0S` (무제한) |

**`ExecutionTimeLimit`을 반드시 바꿔야 합니다.** sync 값인 `PT4H`를 그대로 쓰면 서버가
4시간 뒤에 종료됩니다.

`LogonType`은 sync와 같이 `S4U`를 씁니다. 콘솔 창이 뜨지 않는 근거입니다. **S4U에서
TCP 리스닝이 되는지는 실기로 확인해야 합니다** — S4U는 자격 증명을 저장하지 않아
네트워크 리소스 접근이 제한되는데, 인바운드 리스닝은 로컬 리소스라 될 것으로 보이나
확인되지 않았습니다. 안 되면 `InteractiveToken`으로 내리고 콘솔 숨김은 코드 쪽
메커니즘(v0.2.2)에 맡깁니다.

## 검증

### 단위 테스트

- 비밀번호 저장 후 같은 값으로 검증 성공, 다른 값으로 실패
- 비밀번호 미설정 시 `is_configured()`가 거짓
- `install`이 비밀번호 없이는 끝나지 않음
- 세션 발급 → 검증 성공 → 만료 후 검증 실패
- 검증에 성공하면 만료가 24시간 뒤로 밀림
- 실패 5회 후 잠김, 성공 시 카운터 초기화
- `X-Forwarded-For`를 매번 바꿔도 전역 카운터 20회에서 잠김
- 쿠키 헤더 파싱 (값 하나, 값 여럿, 없음, 빈 값)
- 인증 필요 상태에서 `/api/drives` 401
- 인증 후 `/api/drives` 200
- 비밀번호 미설정 시 `serve`가 실행을 거부
- POST 본문 읽기, `Content-Length` 초과 거부
- serve 작업 XML에 `PT0S`와 `serve --no-open`이 들어감

### 실기 검증

- 실제 Chrome에서 로그인, 오답, 잠금 (검증용 임시 비밀번호를 쓰고, 끝나면 사용자가
  `drive-archive passwd`로 직접 바꾼다 — 개발 중에 쓴 값이 실사용 비밀번호로 남지
  않아야 한다)
- 데스크톱 폭에서 지금과 같은 화면인지 대조
- 모바일 폭(390px)에서 41칸이 잘리지 않는지
- 모바일에서 탭 선택 → 재탭 열기
- Cloudflare Tunnel 경유 접속, `Secure` 쿠키가 실제로 붙는지
- 로그온 작업으로 serve가 창 없이 뜨는지 (S4U 리스닝 확인)

## 하지 않는 것

- **HTTPS 직접 구현** — 터널이 처리합니다. TLS를 직접 넣으면 크레이트가 크게 늘고
  인증서 관리가 따라옵니다.
- **사용자 계정** — 비밀번호 하나입니다. 여러 사람이 쓰는 도구가 아닙니다.
- **웹에서 비밀번호 변경** — 요구사항에서 명시적으로 제외했습니다.
- **비밀번호 복구** — 잊으면 터미널에서 `passwd`로 다시 설정합니다.
- **세션 영속화** — 서버 재시작 시 재로그인합니다.
- **`--host` 옵션** — 바인딩은 127.0.0.1 고정입니다.
- **`cloudflared` 설치·설정** — 사용자가 직접 합니다. README에 방법만 적습니다.

## 남는 위험

- **주소를 고정하려면 준비물이 필요합니다.** 무료 Quick Tunnel(`trycloudflare.com`)은
  `cloudflared`가 뜰 때마다 임의 호스트명을 새로 받아, 컴퓨터를 껐다 켜면 주소가
  바뀝니다. Cloudflare Named Tunnel로 고정하려면 Cloudflare에 등록된 도메인이 필요하고
  (터널과 계정은 무료, 도메인만 유료), 도메인 없이 고정 주소를 원하면 Tailscale
  Funnel이 `https://<기기명>.<테일넷>.ts.net`을 무료로 줍니다. **어느 쪽이든 코드는
  같습니다** — 서버는 127.0.0.1에 뜨고 터널이 앞에 붙습니다. README 안내만 달라집니다.
- **인덱스에는 파일 이름과 경로가 통째로 들어 있습니다.** 비밀번호가 뚫리면 331,174개
  항목의 이름이 전부 보입니다. 파일 내용은 인덱스에 없으므로 내용까지 새지는 않습니다.
- **S4U 리스닝이 안 될 가능성**이 남아 있습니다. 위에 대안을 적어 두었습니다.
